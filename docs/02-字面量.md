# 第二章：字面量

## 2.1 整数字面量

Jasper 支持多种进制整数，允许下划线 `_` 分隔提升可读性：

```jasper
function main(): int {
    var a: int = 42;            // 十进制
    var b: int = 0xFF;          // 十六进制 0x / 0X
    var c: int = 0o77;          // 八进制 0o / 0O
    var d: int = 0b1010;        // 二进制 0b / 0B

    var e: int = 1_000_000;     // 带下划线的十进制
    var f: int = 0xFF_FF;       // 十六进制也可用下划线

    return 0;
}
```

### 2.1.1 类型与取值范围

无后缀整数字面量的类型是 `int32`，带 `L` / `l` 后缀的是 `int64`；字面量的类型不随赋值目标变化
（`var n: int64 = 40000000000;` 是错误，写 `40000000000L`）。超出范围是编译错误，不截断：

| 写法 | 允许的最大值 |
|---|---|
| 无后缀十进制 | `2147483647`；紧跟一元负号时可写 `-2147483648` |
| 无后缀十六 / 八 / 二进制 | 32 位全 1（`0xFFFFFFFF`），按 32 位补码解释，即 `-1` |
| `L` 后缀十进制 | `9223372036854775807L`；紧跟一元负号时可写 `-9223372036854775808L` |
| `L` 后缀十六 / 八 / 二进制 | 64 位全 1，按 64 位补码解释 |

负号只放宽它的直接操作数：`0 - 2147483648` 仍是错误。

## 2.2 浮点数字面量

```jasper
function main(): int {
    var a: float = 3.14;        // 标准小数
    var b: float = .5;          // 省略整数部分
    var c: float = 1.0e10;      // 科学计数法
    var d: float = 1e-5;        // 负指数
    var e: float32 = 3.14f;     // 类型后缀 f / F
    var f: float64 = 3.14d;     // 类型后缀 d / D

    var g: float = 0x1.0p10;    // 十六进制浮点数 0x / 0X

    return 0;
}
```

### 2.2.1 十六进制浮点数

`0x` 后是十六进制有效数字（可带小数点），再接**必需的**二进制指数 `p` / `P`（十进制，可带正负号），
值 = 有效数字 × 2^指数：`0x1.8p1` 是 `3.0`，`0x.Cp-2` 是 `0.1875`。类型后缀 `f` / `F`（float32）、
`d` / `D`（float64）只能写在指数之后；没有指数的 `0x1.8` 是编译错误，因为末尾的 `f` / `d` 也是十六进制数字。

数值按目标类型就近舍入（平局取偶），float32 直接从精确值舍入，不经 float64 中转。舍入后超出有限范围
（如 `0x1p1024`、`0x1p128f`），或非零值舍入成 0（如 `0x1p-1075`、`0x1p-150f`）都是编译错误。

## 2.3 字符串字面量

```jasper
function main(): int {
    // 普通字符串
    var s1: string = "Hello, Jasper!";

    // 转义字符
    var s2: string = "line1\nline2\tindented";

    // 原始字符串 r"..."（不处理转义）
    var s3: string = r"C:\Users\name\file.txt";

    // 正则字面量 re"..."
    var s4: regex = re"\d{3}-\d{4}";

    // 格式化字符串 f"..."（支持插值 {expr}）
    var name: string = "World";
    var s5: string = f"Hello, {name}!";

    // 字节字符串 b"..."
    var s6: bytes = b"\x00\x01\x02";

    // Unicode 字符串 u"..."
    var s7: string = u"\u4e2d\u6587";  // "中文"

    // 字符字面量 '...'
    var ch: char = 'A';
    var nl: char = '\n';

    // 三引号字符串（支持多行）
    var s8: string = """
        这是多行字符串
        可以跨多行
        缩进和换行保留
        """;

    // 原始三引号字符串
    var s9: string = r"""
        原始多行字符串
        转义序列 \n 不会被处理
        """;

    // 格式化三引号字符串
    var s10: string = f"""
        多行插值：{name}
        计算：{1 + 2}
        """;

    return 0;
}
```


### 2.3.1 转义序列（Q239，2026-11-15）

普通字符串与字符字面量接受同一组转义（与词法 `CHAR_ESCAPE` 一致）：

| 写法 | 含义 |
|---|---|
| `\n` `\t` `\r` | 换行、制表、回车 |
| `\b` `\f` | 退格（U+0008）、换页（U+000C） |
| `\\` `\"` `\'` | 反斜杠、双引号、单引号 |
| `\xHH` | 码点 U+0000..U+00FF（恰好 2 位十六进制） |
| `\uHHHH` | 一个 UTF-16 码元（恰好 4 位）；`\uD83D\uDE00` 两个码元合成一个补充平面字符 |

其他反斜杠组合、位数不足的 `\x` / `\u` 是编译错误。`char` 字面量必须是一个 Unicode scalar：孤立代理（如 `'\uD83D'`）是编译错误。
原始字符串 `r"..."` 不处理转义。

## 2.4 布尔与 null

```jasper
function main(): int {
    var t: bool = true;
    var f: bool = false;

    var n: int? = null;     // null 表示空值

    if (t) {
        return 1;
    }
    return 0;
}
```

## 2.5 dict 字面量

Jasper 使用 `dict{ ... }` 语法创建字典。key 可以是任意表达式：

```jasper
function main(): int {
    // 空字典
    var empty: dict<string, int> = dict{};

    // 基本键值对
    var scores: dict<string, int> = dict{
        "Alice": 95,
        "Bob": 87,
        "Charlie": 92
    };

    // key 支持任意表达式
    var prefix: string = "user_";
    var data: dict = dict{
        1: "one",
        prefix + "1": "first",
        true: "yes"
    };

    // 允许尾逗号
    var map: dict = dict{
        "a": 1,
        "b": 2,
    };

    return 0;
}
```

## 2.6 JSON（已移出语言核心）

`json` 关键字与 `json{ ... }` 字面量**已从语言核心移除**（收敛方案 A4）：

- 删除 `jsonLiteral` / `jsonEntry` / `jsonValue` 及 7 个 `#Json*` 标签；
- lexer 的 `Json` token 一并删除；
- JSON 支持**由标准库提供**（作为标准库类型/注解，而非语言关键字）。

> **【待定，未裁决】** JSON 字面量是否需要以一种语言级语法回归，目前**尚未裁决**。
> 本文档不把它写成已实现或已定能力。在裁决之前，请使用标准库提供的 JSON 能力，
> 不要书写 `json{ ... }`。

## 2.7 数组初始化器

Jasper 使用 `[...]` 创建数组字面量，与数组类型 `int[]` 的语法呼应：

```jasper
function main(): int {
    // 数组字面量
    var arr: int[] = [1, 2, 3, 4, 5];

    // 带尾逗号
    var arr2: int[] = [
        1,
        2,
        3,
    ];

    return 0;
}
```

## 语法对照

| 特性 | Parser / Lexer 规则 | 对应代码 |
|------|---------------------|---------|
| 十进制整数 | `DEC_LITERAL` | `42`, `1_000_000` |
| 十六进制整数 | `HEX_LITERAL` | `0xFF`, `0xAB_CD` |
| 八进制整数 | `OCT_LITERAL` | `0o77`, `0o777` |
| 二进制整数 | `BIN_LITERAL` | `0b1010`, `0b11_00` |
| 浮点数 | `FLOAT_LITERAL` | `3.14`, `1e10`, `.5f` |
| 十六进制浮点数 | `HEX_FLOAT_LITERAL` | `0x1.0p10` |
| 普通字符串 | `STRING_LITERAL` | `"hello"` |
| 原始字符串 | `RAW_STRING_LITERAL` | `r"raw"` |
| 正则字面量 | `REGEX_LITERAL` | `re"\d+"` |
| 格式化字符串 | `FORMAT_STRING_LITERAL` | `f"hello {name}"` |
| 字节字符串 | `BYTE_STRING_LITERAL` | `b"\x00"` |
| Unicode 字符串 | `UNICODE_STRING_LITERAL` | `u"\u4e2d"` |
| 字符 | `CHAR_LITERAL` | `'A'`, `'\n'`, `'\u4e2d'` |
| 三引号字符串 | `TRIPLE_STRING_LITERAL` | `"""..."""` |
| 原始三引号 | `RAW_TRIPLE_STRING_LITERAL` | `r"""..."""` |
| 格式化三引号 | `FORMAT_TRIPLE_STRING_LITERAL` | `f"""..."""` |
| 布尔 | `True` / `False` | `true`, `false` |
| null | `Null` | `null` |
| dict | `dictLiteral` | `dict{ "a": 1 }` |
| 数组初始化 | `arrayInitializer` | `[1, 2, 3]` |

> 注：dict 的 key 是 `expression`（任意表达式），value 是 `expression`。
> `json{ ... }` 已移出语言核心（见 §2.6），不再有对应的 parser/lexer 规则。
