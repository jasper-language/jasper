# 第一章：入门与基础

## 1.1 文件结构

每个 `.jas` 文件**恰好包含一个顶层类型声明**，其前可选的顺序为：
`package` 声明、若干 `import` / `from` 导入，随后是**唯一**的顶层类型声明，最后是文件结束。

顶层类型只能是 `class`、`interface`、`enum` 或 `@interface`（注解类型）。

**顶层函数、顶层变量、顶层语句都不是合法的文件项**（这是语言层的硬约束，见 `sourceFile`）。

> 实现注记：当前编译器保留了一个遗留兼容包装（内部类型 `__JasperCompatTopLevel`），
> 使脚本式写法仍能编译通过。这**不属于已定语言语义**，属于待清理项。
>
> 后续章节的代码片段为聚焦语法，常有省略外层类型声明的情况（例如直接给
> `function` 片段）；完整文件必须遵守本节的文件结构规则。

## 1.2 最简单的 Jasper 程序

```jasper
package org.example.myapp;

public class Main {
    public static function main(): void {
        println("Hello, Jasper!");
    }
}
```

程序入口是类中的静态 `main` 函数（`public static function main(): void`）。

## 1.3 package 声明

```jasper
package org.example.myapp;

public class Main { }
```

`package` 声明包路径，用 `;` 结尾。它是可选的。

## 1.4 import 导入

```jasper
package org.example.myapp;

import std.io.File;              // 导入单个类型
import std.util.*;               // 按需导入（通配符）

public class Main { }
```

导入规则只支持两种形态：

```antlr
importDeclaration
    : Import qualifiedName ';'
    | Import qualifiedName '.' '*' ';'
    | fromImportDeclaration
    ;
```

> 没有 Java 风格的 `import static ...`（静态成员导入）。`static` 不是导入关键字。

## 1.5 from-import 导入（Jasper 特色）

```jasper
package org.example.myapp;

from std.math import sin, cos;            // 导入多个
from std.math import sin, cos as c;       // 别名导入
from "com/example/utils" import *;        // 字符串路径导入

public class Main {
    public function run(): void {
        var x: float64 = sin(0.0);
    }
}
```

来源位置只接受两种写法：`qualifiedName`（限定名）或 `STRING_LITERAL`（字符串字面量）：

```antlr
fromImportDeclaration
    : softFrom qn=qualifiedName Import clause=importClause ';'
    | softFrom s=STRING_LITERAL Import clause=importClause ';'
    ;
```

`from` 是**真软关键字**（在非导入语境下可作普通标识符）；`as` 是**硬保留字**。
详见第十一章。

## 1.6 注释

```jasper
// 行注释

/* 块注释 */

/**
 * 文档注释（语法层与块注释相同，语义层由 Checker 按需处理）
 */
```

## 1.7 关键字：软关键字与保留字（摘要）

- **真软关键字**：`get`、`set`、`from`、`then`、`where`——仅在被引用的语境生效，别处可作普通标识符。
- **有意保持硬保留**：`as`、`cast`、`label`、`is`、`and`、`or`、`not`。
- **保留但未启用**（lexer token，parser 零引用）：
  `raw`、`shared`、`weak`、`auto`、`unique`、`atomic`、`pointer`、`handle`、`locked`、`delete`、`destructor`。

完整对照与理由见第十一章。

## 语法对照

| 特性 | Parser 规则 | 对应代码 |
|------|-------------|---------|
| 文件入口 | `sourceFile` | `package? import* topLevelTypeDeclaration EOF` |
| package | `packageDeclaration` | `package name;` |
| import | `importDeclaration` | `import X;` / `import X.*;` |
| from-import | `fromImportDeclaration` | `from X import Y;` / `from "p" import *;` / `from X import Y as Z;` |
| 顶层类型 | `topLevelTypeDeclaration` | `class` / `interface` / `enum` / `@interface` |

所有声明和语句都以 `;` 结尾。语句块用 `{ }`。
