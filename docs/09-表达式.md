# 第九章：表达式

## 9.1 表达式入口

```antlr
expression
    : lambdaExpression
    | assignmentExpression
    ;
```

## 9.2 Lambda

Lambda 使用 `lambda (...) { ... }`：

```jasper
var zero = lambda () {
    return 0;
};

var add = lambda (a: int32, b: int32) {
    return a + b;
};
```

不支持无括号单参数 lambda，也不使用 `=>` 作为正式语法。
Lambda 不能带 identifier，也不在 lambda 语法里声明返回类型；返回类型由左侧目标类型或 checker 推断。

```jasper

```

## 9.4 Null 表达式

`??` 是表达式层 null coalescing：

```jasper
var name: string = maybeName ?? "anonymous";
```

类型层不存在 `T??`。

方法风格可由标准库提供：

```jasper
var name = maybeName.orElse("anonymous");
var user = maybeUser.expect("missing user");
```

## 9.5 一元表达式

```antlr
unaryExpression
    : '+' unaryExpression
    | '-' unaryExpression
    | '*' unaryExpression
    | '&' unaryExpression
    | '~' unaryExpression
    | (Not | '!') unaryExpression
    | awaitExpression
    | goExpression
    | castExpression
    | primary
    ;
```

指针相关：

```jasper
var x: int32 = 1;
var p: *int32 = &x;
var y: int32 = *p;
```

- `&expr` 是取地址表达式。
- `*expr` 是解引用表达式。
- `&T` 不是类型语法。

## 9.6 二元运算符与优先级

二元表达式规则 `binaryExpression` 采用**直接左递归**，各分支的书写顺序即
**从高到低的优先级**（权威文法 `jasper-grammar` main）：

```antlr
binaryExpression
    : unaryExpression                                                    #BinaryUnary
    | binaryExpression op=(STAR | SLASH | PERCENT) binaryExpression      #BinaryMultiplication
    | binaryExpression op=(PLUS | MINUS) binaryExpression                #BinaryAddition
    | binaryExpression op=(LSHIFT | RSHIFT | URSHIFT) binaryExpression   #BinaryShift
    | binaryExpression op=(LT | GT | LE | GE) binaryExpression           #BinaryRelational
    | binaryExpression op=(EQUAL_EQUAL | NOT_EQUAL) binaryExpression     #BinaryEquality
    | binaryExpression op=AMP binaryExpression                           #BinaryBitAnd
    | binaryExpression op=CARET binaryExpression                         #BinaryBitExclusiveOr
    | binaryExpression op=(PIPE | FULLWIDTH_PIPE) binaryExpression       #BinaryBitOr
    | binaryExpression op=(And | AND_AND) binaryExpression               #BinaryAnd
    | binaryExpression op=(Or | OR_OR) binaryExpression                  #BinaryOr
    ;
```

优先级由高到低（序号越小越紧，与 C/Java 一致）：

| 优先级 | 运算符 | 结合性 | 备注 |
|--------|--------|--------|------|
| 1 | 一元 `+ - * & ~ !` / `not` / `await` / cast | 前缀（右） | 见 9.5 |
| 2 | `*` `/` `%` | 左 | 乘除取模 |
| 3 | `+` `-` | 左 | 加减 |
| 4 | `<<` `>>` `>>>` | 左 | 移位 |
| 5 | `<` `>` `<=` `>=` | 左 | 关系 |
| 6 | `==` `!=` | 左 | 相等 |
| 7 | `&` | 左 | 按位与 |
| 8 | `^` | 左 | 按位异或 |
| 9 | `\|` `｜` | 左 | 按位或（含全角 `｜`） |
| 10 | `&&` / `and` | 左 | 逻辑与（短路） |
| 11 | `\|\|` / `or` | 左 | 逻辑或（短路） |

要点：

- **右侧操作数递归到 `binaryExpression`**（而非更低层的 `unaryExpression`），
  这样优先级与结合性真实生效：`1 + 2 * 3` 解析为 `+(1, *(2, 3))` = `7`，
  而不是被展平成 `(1 + 2) * 3 = 9`。
- **所有二元运算符都是左结合**：`10 - 3 - 2` = `10 - (3) - 2` = `5`。
- 注释中出现的 `and` / `or` 是 `&&` / `||` 的可读别名（见第十一章），
  解析后归一为 `&&` / `||`；`not` 是一元逻辑非。
- 更松的层在其上：`??`（9.4）比任意二元运算松，`?:` 三元比 `??` 松，
  赋值最低且右结合。

## 9.7 Task 和 Await

**`go` 不是关键字**（2026-10-17 裁决：删除该语法糖，`go` 现为普通标识符）。
启动任务由标准库承担（`Task` 协议，**工厂形态待标准库增量定稿**），
关键是**必须拿到句柄**——这样才能等待、取消，也才能让 `.jaso` 模块卸载
基于"是否还有活跃任务"做决策：

```jasper
// Task 协议：join() 取值、isDone() 判断完成（工厂由标准库提供）
var task: Task<int32> = startWorker();
var result = await task.join();
```

## 9.8 Cast

当前保留 cast 表达式入口：

```jasper
var n = (int32) value;
var user = cast value as User;
```

交集类型 cast 如 `(A & B) value` 不作为第一版核心类型设计。
