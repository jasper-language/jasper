# 第四章：变量与声明

## 4.1 绑定语法

Jasper 的核心绑定语法是：

```jasper
name: Type
```

变量声明使用 `var` 或 `const`：

```jasper
var name: string = "Jasper";
const version: string = "1.0";
```

- `var`：绑定可重新赋值。
- `const`：绑定不可重新赋值。
- 变量使用前必须初始化。

## 4.2 类型推断

类型可以由初始化表达式推断：

```jasper
var count = 1;
const title = "Hello";
```

## 4.3 多绑定

Jasper 支持 Go 风格多返回/多赋值：

```jasper
function userInfo(): (string, int32) {
    return "Ada", 36;
}

var name, age = userInfo();
```

数量必须匹配，否则是编译错误。

### 4.3.1 按位置绑定与普通多声明的区分（Q223，2026-11-10）

语法上 `variableBinding (',' variableBinding)*` 允许每个绑定各带初始化器，编译器按下面的规则区分两种写法：

- **按位置绑定**：两个以上名字，**只有最后一个**带初始化器，且所有名字都不写类型标注。
  初始化器必须是元组，元数等于名字个数；第 i 个名字取第 i 个元素，类型就是该元素的类型。
  不是元组或元数不符是编译错误（`Positional binding of N names needs a tuple of N values`）。
  `const q, r = divide(17, 5);` 同样适用，绑定出的名字都是常量。
- **普通多声明**：其余写法，如 `var a = 1, b = 2;`、`var a: int32, b = 5;`，各名字独立声明，行为不变。

初始化器只求值一次。

普通变量声明不支持 tuple pattern：

```jasper
var (name, age) = userInfo(); // 非法
```

for-in 可以使用 tuple pattern：

```jasper
for ((k, v) in map) {
    println(k);
    println(v);
}
```

> `for (a, b in xs)` 这类多名字绑定能解析，但编译器报错，不会只绑定第一个名字。均已入队待实现。

## 4.4 延迟初始化

`late` 不作为关键字语法。需要延迟初始化标记时使用注解：

```jasper
@Late
var cache: string;
```

`@Late` 的语义由 checker 或框架层定义；parser 只把它作为普通注解处理。

## 4.5 顶层变量（不是合法文件项）

**顶层变量不是合法的文件项**：`sourceFile` 要求恰好一个顶层**类型**声明。
变量必须作为**类型成员**或**局部变量**出现。

```jasper
package app;

public class App {
    public static var globalCount: int64 = 0;
    public const APP_NAME: string = "JasperApp";
}
```

> 实现注记：当前编译器保留了遗留兼容包装 `__JasperCompatTopLevel`，
> 使脚本式顶层写法仍能编译；它不属于已定语言语义，属于待清理项。

## 4.6 局部变量

局部变量出现在函数或块内部：

```jasper
public class Example {
    public function localDemo(): void {
        var local: int64 = 0;
        const inner: string = "inner";
    }
}
```

## 4.7 注解化扩展

导出、延迟初始化、装饰器等扩展不使用独立关键字语法，统一使用注解：

```jasper
@Export
class User { }

@Late
var cache: string;

@Decorate
function f(): void { }
```

## 4.8 语法对照

| 特性 | Parser 规则 | 示例 |
|------|-------------|------|
| 变量声明 | `variableDeclarationTail` | `var x: int64 = 1;` |
| 常量声明 | `variableDeclarationTail` | `const x: int64 = 1;` |
| 绑定 | `binding` | `name: Type` |
| 多绑定 | `variableBinding (',' variableBinding)*` | `var a, b = pair;` |
| 注解 | `annotation` | `@Late var cache: string;` |
