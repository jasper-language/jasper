## 10.2 变量声明

核心绑定语法是：

```jasper
var name: Type = value;
const name: Type = value;
```

变量声明支持 Go 风格多绑定：

```jasper
var name, age = getUserInfo();
```

普通变量声明不支持 `var (a, b) = pair`。for-in 支持 tuple pattern：

```jasper
for ((k, v) in map) {
    println(k);
    println(v);
}
```

## 10.3 If

```jasper
if (x > 0) {
    println("positive");
} else {
    println("non-positive");
}
```

主体必须是 block。

## 10.4 Switch

```jasper
switch (code) {
    case 200 => {
        println("OK");
    }
    case 404 => {
        println("missing");
    }
    default => {
        println("unknown");
    }
}
```

规则：

- 没有 `match`。
- `switch` 必须有 `default`。
- `default` 只能出现一次，并且必须放在最后。
- `case => block` 不 fallthrough，不需要 `break`。
- 当前没有 `case if` guard。

## 10.5 循环

```jasper
while (i < 10) {
    i = i + 1;
}

do {
    poll();
} while (running);

for (var i: int32 = 0; i < 10; i = i + 1) {
    println(i);
}

for (item in items) {
    println(item);
}
```

### 10.5.1 循环后置块（G3）

`for-in` 和 `while` 的循环体后可以跟任意子集的三个后置块；它们互斥，
一次循环最多执行一个。`onComplete` / `onBreak` / `onZeroRuns` 是上下文软关键字：
只在这个位置被识别，其他位置仍然是普通标识符。

```jasper
for (x in xs) {
    if (x < 0) { break; }
} onComplete {
    // 至少执行过一次，且没有被本循环的 break 打断
} onBreak {
    // 被 break 或 break label 打断；continue 不算
} onZeroRuns {
    // 循环体一次也没有执行
}
```

语义与实现约束：

- 三个块按 `onBreak` → `onComplete` → `onZeroRuns` 的互斥顺序选择；最多执行一个。
- `continue` 不触发 `onBreak`；`return`/`throw` 提前退出时不执行任何后置块。
- `break outer` 只触发 `outer` 的 `onBreak`，不触发内层循环的 `onBreak`。
- 旧循环 `then { } else { }` 已移除；`else` 只属于 `if`。
- 经典三段式 `for` 暂不支持后置块；`do-while` 本轮不涉及 `onZeroRuns`。

## 10.7 Throw / Try / Catch / Finally

当前确认的异常控制流：

```jasper
throw err;

try {
    risky();
} catch (e: Error) {
    onError(e);
} finally {
    cleanup();
}
```

不引入额外错误处理语法作为第一版核心。

try-with-resources 保留，用于把资源生命周期绑定到 try 块：

```jasper
try (var f = open("file.txt")) {
    use(f);
} catch (e: Error) {
    onError(e);
}
```

`defer` 仍用于当前作用域退出时的通用清理逻辑。

## 10.8 Future / Await / Defer

**`go` 不是关键字**（2026-10-17 裁决移除该语法糖）。公开的异步结果类型是
`Future<T>`（2026-10-20 W-20 裁决）：异步 API 返回 `Future<T>`，`await` 等待并取值。
`Task` 是运行时内部的执行实体，**不公开**。采用结构化并发：子任务由 `TaskGroup`
持有，取消、生命周期与错误传播统一由它负责。以上 `Future` 运行时、`Task` 与
`TaskGroup` 均**已裁决、未实现**，当前运行时真异步尚未实现。

`defer` 在当前作用域结束时执行：

```jasper
public class Worker {
    public function run(): void {
        var future: Future<int32> = startWorker();
        var result = await future;
    }

    public function readFile(path: string): string {
        var f = open(path);
        defer close(f);
        return f.read();
    }
}
```

## 10.9 Lock

`lock` 是并发控制语句，不是修饰符。Jasper 使用 `lock`，不使用 `locked` 作为控制流关键字：

```jasper
lock (mutex) {
    criticalSection();
}
```

`locked` 如未来需要，可作为库注解或保留词另行设计；当前核心语法只确认 `lock (expr) { ... }`。
