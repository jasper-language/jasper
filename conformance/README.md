# Jasper 语言一致性测试集

本目录保存「规范语义」的可执行一致性用例。每个用例是一段完整、可独立编译的
Jasper 源码；用例头部用注释声明它对应的规范条目与期望结果，运行器只负责编译、
执行并比对，不关心具体后端。

英文摘要：Each `.jas` file is a self-contained conformance case. A comment header
declares the spec section and the expected exit code or rejection diagnostic; a
replaceable backend compiles and runs the case.

## 目录与命名

- 一级子目录与 `docs/` 的章节文件一一对应，例如 `10-语句与控制流/` 对应
  `docs/10-语句与控制流.md`。
- 每个用例一个文件，命名为 `<语义短名>.<pos|rej|edge>.jas`：
  - `pos`：规范允许的正例，程序应成功编译并以指定值退出；
  - `rej`：规范禁止的写法，编译应被拒绝且诊断包含指定片段；
  - `edge`：边界或容易回归的点，程序应成功编译并以指定值退出。
- 语义短名使用小写 ASCII、数字与连字符，避免空格与路径分隔符。

## 用例头部格式

头部必须位于文件最前面，由 `//` 注释行组成：

```jasper
// spec: 10-语句与控制流.md#10.5 循环
// kind: pos
// expect: exit 6
```

- `spec:`：`docs/` 下的真实文件名，加 `#`，再加该文件中真实存在的小节标题
  （标题文本与 `#`/`##`/`###` 后面的内容完全一致）。运行器会校验文件和小节，
  两者任一不存在都会让用例失败。
- `kind:`：只能是 `pos`、`rej`、`edge`。
- `expect:`：
  - `pos` / `edge` 写 `exit <整数>`，表示 `main` 的返回值；
  - `rej` 写 `reject <诊断片段>`，表示编译必须失败，且任一诊断消息包含该片段。
- 头部字段不得重复；缺少字段、未知字段值或字段与期望类型不匹配都会产生带文件
  名的解析错误。
- 头部之后必须是完整源文件（含 `package` 与 `main`），以保证可独立编译。

## 如何新增用例

1. 在对应章节目录新建 `<语义短名>.<kind>.jas`。
2. 从规范中挑一条可观察的语义，写出最小完整程序；只使用当前编译器已支持的
   语义，不要为了用例去改编译器或文法。
3. 填好头部，并确认 `spec:` 指向真实文件与真实小节标题。
4. 运行一致性测试；若编译器的实际行为与规范不一致，先在下方「待补」表登记，
   不要通过放宽断言让用例变绿。
5. 每个新增语义至少提供一条正例或边界例，并为明确的禁止项提供拒绝例。

## 如何运行

```bash
./gradlew :jasper-compiler:test --tests 'jasper.conformance.*' --no-daemon --console=plain
```

运行器会递归发现本目录下所有 `.jas` 文件，每个文件生成一个动态测试。编译产物
写入仓库内的 `jasper-compiler/build/conformance/`，不会写到项目外路径。

新增后端时，实现 `ConformanceBackend` 接口并在测试中替换实现即可；用例本身与
后端无关。

## 当前覆盖与「待补」

首批种子用例只覆盖当前编译器已支持的语义，不追求覆盖率。以下语义已记录为待补，
在编译器具备稳定行为后再补用例：

| 章节 | 语义 | 待补原因 |
|------|------|----------|
| 02-字面量 | `dict{...}` 字面量 | 尚未纳入端到端编译执行用例 |
| 02-字面量 | 格式化字符串 `f"..."` 与三引号字符串 | 尚未纳入端到端编译执行用例 |
| 02-字面量 | 可空局部变量赋 `null` 后参与比较或 `??` | 当前后端在该边界上运行期验证失败，行为不稳定 |
| 04-变量与声明 | 内层块遮蔽同名局部变量 | 当前类型检查按同一作用域判重，遮蔽语义尚未裁决 |
| 09-表达式 | `int32` 与 `int64` 字面量的跨宽度相等比较 | 运行期结果不符合直觉（`5 == 5L` 为假），语义待确认 |
| 05-函数 | Lambda 的调用与返回类型推断 | 只验证过赋值，未纳入调用用例 |
| 10-语句与控制流 | `try/catch/finally`、`defer`、`lock` | 语法已存在，端到端一致性用例待补 |
